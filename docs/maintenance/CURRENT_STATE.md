- Журнал подтверждает загрузку 6.08.66 и ошибочную фразу шесть раз между

  движении. Num5 учитывал только звуковую навигацию и игровую цель, пропуская
  выбранную в списке метку. Само нажатие доходило до обработчика.
- Num5 теперь читает выбранную цель из общего обработчика целей навигации:
  метки заданий, места, объекты и прочие поддерживаемые категории. Для чтения
  не нужны готовая сетка vnavmesh, запуск движения или выделение объекта игрой.
  При отсутствии выбора в списке сохранены основная/временная игровые цели;
  активное движение к координатам даёт запасной источник цели.
- Чтение не поворачивает персонажа/камеру, не меняет противника и не переключает
  участок поиска охоты. Для меток с неизвестной высотой читается горизонтальное
  расстояние без выдуманной подсказки высоты. Звуковая навигация Ctrl+Num3
  сохраняет поворот по маршруту, меню Ctrl+Num0 — чтение описания умения.
- Release собран, 0 ошибок и 9 прежних предупреждений. Пройдены 52 теста,
