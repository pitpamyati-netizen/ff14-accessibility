## Что установлено сравнением

для каждого проверен SHA-256 полной резервной копии перед переносом.
Папка проекта получила постоянное имя `FF14Accessibility` без номера версии.
Сведения о расположении полной копии на этом компьютере находятся в `.local/recovery.json`.

Каталог плагина содержит 277 исходных файлов и ресурсов без `bin/obj`:
все 254 файла автора на месте, 224 совпадают после нормализации переносов строк,
30 отличаются, ещё 23 добавлены нами. Для C# это 100 совпадающих, 28 изменённых
и 23 добавленных файла. Последние изменения автора уже находились в нашей версии;
заново накладывать старую версию поверх новой не потребовалось.

Восстановлен 91 отсутствовавший файл вне каталога плагина: исходники установщика,
документация, тесты, настройки и инструменты. Ни один файл автора не удалён.
Авторские исправления UI версии 6.08.33/34 проверены отдельно: все 74 и 17
непустых добавленных строк соответственно присутствовали в нашем коде.

## Изменения после исходного снимка

- Русские названия мест охоты и ограничений экипировки применяются только в русском
  режиме. На других языках сохранены названия из игровых таблиц.
- Подсказка о переназначении старого ремесленного навыка переведена на три языка.
- Немецкие и английские подсказки команд Penumbra используют `on/off`;
  немецкое сообщение о дополнительных противниках также исправлено.
- Категория ремесленного класса сопоставляется с английским сокращением по английской
  таблице; язык клиента больше не меняет источник сравнения.
- Исправлен неточный текст диагностической записи: она больше не утверждает, что
  вызван `LoadSavedHotbar`, когда он намеренно не вызывается.
- Убраны лишние пробелы в восстановленных файлах, без изменения логики.
- Подготовлены инструкции, отдельные каталоги результатов и повторяемые команды сборки,
  проверки и упаковки. Установщик понимает новый путь `artifacts/plugin`.
