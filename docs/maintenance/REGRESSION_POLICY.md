# Защита существующих функций

## Обязательная проверка перед выдачей сборки

Запустить `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/Verify-Local.ps1`.
Он выполняет сборку, все тесты и упаковку в этом порядке. Отдельные прежние команды
тоже доступны. Предупреждения останавливают сборку; их нельзя скрывать ради выпуска.

`tests/required-projects.json` содержит обязательные проекты тестов. Если проект
исчезнет или появится новый, список нужно явно согласовать с изменением.
Ноль выполненных тестов, пропуски и ошибки считаются неуспешной проверкой.

Упаковка требует успешного отчёта `artifacts/test-info.json` именно для текущих
исходников плагина, русского установщика, тестов и проверочных скриптов.
Изменение этих файлов после проверки требует повторного запуска тестов.
Отпечаток сборки и проверка всех файлов ZIP продолжают действовать отдельно.
Сам отказ выпуска также проверяется на одиннадцати искусственных ситуациях,
включая изменение закреплённого снимка автора.

## При изменении функции

1. Установить фактическую причину по актуальному коду и, для поведения игры,
   по журналу пользователя. Старую запись не считать проверкой новой версии.
2. Для исправления серьёзной ошибки добавить воспроизводимый тест, который
   отличает правильное поведение от наблюдавшейся ошибки. Использовать реальные
   входные данные, когда они доступны. Не заменять проверку поведения поиском
   нужной строки в исходнике.
3. Проверить связанные функции по таблице ниже. Новую функцию добавлять в эту
   таблицу вместе с объяснением, как её проверить.
4. Выполнить общий набор проверок и записать результаты в `VERIFICATION.md`.
   Не объявлять непроверенное поведение в FFXIV подтверждённым.

Это защита от известных повторных ошибок, а не обещание отсутствия любых будущих
дефектов. Автоматические проверки не воспроизводят сам клиент FFXIV, его задержки,
все окна и чужие плагины. Изменения нативных действий требуют проверки в игре.
С 6.08.91 пользователь потребовал вернуть авторскую автонавигацию целиком.
Прежние обязательства проверять каждый пеший путь, строить отдельные отменяемые
запросы, искать дополнительные обходы/прыжки и отбрасывать этажи больше не применяются:
эти алгоритмы и их тесты удалены. Действующие проверки перечислены в строке
авторской автонавигации. Их замена не объявляет старые игровые проблемы
исправленными: новая версия требует фактической проверки пользователем в игре.
