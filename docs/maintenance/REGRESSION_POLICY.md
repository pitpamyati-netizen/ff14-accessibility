# Защита существующих функций

## Обязательная проверка перед выдачей сборки

Запустить `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/Verify-Local.ps1`.
Он выполняет сборку, все тесты и упаковку в этом порядке. Отдельные прежние команды
тоже доступны. Предупреждения останавливают сборку; их нельзя скрывать ради выпуска.

`tests/required-projects.json` содержит обязательные проекты тестов. Если проект
исчезнет или появится новый, список нужно явно согласовать с изменением.
Ноль выполненных тестов, пропуски и ошибки считаются неуспешной проверкой.

Упаковка требует успешного отчёта `artifacts/test-info.json` именно для текущих
исходников плагина, русского установщика, тестов и проверочных скриптов.
Изменение этих файлов после проверки требует повторного запуска тестов.
Отпечаток сборки и проверка всех файлов ZIP продолжают действовать отдельно.
Сам отказ выпуска также проверяется на десяти искусственных ситуациях.

## При изменении функции

1. Установить фактическую причину по актуальному коду и, для поведения игры,
   по журналу пользователя. Старую запись не считать проверкой новой версии.
2. Для исправления серьёзной ошибки добавить воспроизводимый тест, который
   отличает правильное поведение от наблюдавшейся ошибки. Использовать реальные
   входные данные, когда они доступны. Не заменять проверку поведения поиском
   нужной строки в исходнике.
3. Проверить связанные функции по таблице ниже. Новую функцию добавлять в эту
   таблицу вместе с объяснением, как её проверить.
4. Выполнить общий набор проверок и записать результаты в `VERIFICATION.md`.
   Не объявлять непроверенное поведение в FFXIV подтверждённым.

| Изменяемая часть | Что должно сохраниться | Автоматическая и игровая проверка |
| --- | --- | --- |
| Инвентарь, перевод меню | Alt+F3 использует штатную команду для своего предмета | Regression.Tests: меню из журнала 6.08.74, переводы, задержка, недоступность, неоднозначность, подтверждение обеих сторон. В игре: один ненужный предмет, четыре страницы сумки, полный раздел сундука, закрытие окна |
| Панели, клавиши | CraftAction и Action различаются; Ctrl+Num0 начинает с клавиши; Num5 читает без назначения | CrossHotbar.Tests, Regression.Tests. В игре: назначить оба типа, проверить действие, смену класса и перезапуск; клавиатуру при включённом геймпаде |
| Чат, речь, бой | История сохраняется; автоматическая речь Action молчит; союзники не считаются врагами | Regression.Tests: союзники, отправитель строки, сервер, проценты здоровья. В игре: речь противника, тишина союзников, история, обе системы чата |
| Перевод, рецепты, задания | Язык переключается; исходные числа и типы не меняются; два рецепта не смешиваются | Localization.Tests, RussianDescriptions.Tests, SpeechLocalization.Tests. В игре: смена рецепта, материалы NQ/HQ и кристаллы, неоднозначное название задания |
| Синтез и материалы | CP включает ноль; ручное чтение повторяет состояние; количества и запасы не пропадают и не берутся от другого рецепта | Regression.Tests/CraftingTests: CP из персонажа, изменения эффектов, пустые поля, полный запас больше 255, русский заголовок, другой и неполный рецепт. В игре: Ctrl+F10 в журнале и синтезе, действие с расходом/восстановлением CP, смена рецепта и завершение эффектов |
| Навигация, Num5 | Чтение цели не запускает движение; отменённый поиск не возобновляет ходьбу | Navigation.Tests. В игре: цель без маршрута, маршрут, остановка и переход зоны |
| Penumbra | Повторное отключение не теряет список восстановления; повтор восстановления касается только неудачных записей | Regression.Tests с имитацией ответов Penumbra. В игре: отключение, частичная ошибка и повтор восстановления |
| Установка, сборка | Рабочие настройки и резервные копии сохраняются; выдаётся проверенный пакет | Installer.Tests, проверки выпуска, сверка SHA-256. После установки: загрузка версии и короткая проверка речи |

Это защита от известных повторных ошибок, а не обещание отсутствия любых будущих
дефектов. Автоматические проверки не воспроизводят сам клиент FFXIV, его задержки,
все окна и чужие плагины. Изменения нативных действий требуют проверки в игре.
