# Выпуск русской версии на GitHub

Файлы публикуются в [релизах этого репозитория](https://github.com/pitpamyati-netizen/ff14-accessibility/releases).
Публикация выполняется по запросу владельца; обычное изменение исходников
само по себе не выпускает новую версию.

## Файлы для игроков и разработчиков

- `FF14AccessibilityInstaller.exe` — автоматическая установка и обновление.
- `FF14Accessibility-ВЕРСИЯ-RU-no-source.zip` — папка `plugin`, инструкция и
  лицензии для ручной установки. В нём нет скриптов установки, EXE или исходников.
- `SHA256SUMS.txt` — контрольные суммы ZIP мода и DLL внутри него.
- `FF14AccessibilityInstaller-ВЕРСИЯ-source.zip` — отдельные исходники установщика.
- `installer-SHA256SUMS.txt` — контрольные суммы EXE и его исходников в выпуске 6.08.73.
- GitHub Source code — исходники плагина по метке выпуска.

Установщик 1.0.0 добавлен после создания метки v6.08.73. Поэтому его исходники
нужно брать из отдельного архива, а не из автоматически созданного GitHub Source code.
Имя ZIP мода сохраняет форму `FF14Accessibility-ВЕРСИЯ-RU-no-source.zip`:
по этому имени EXE находит пакет в релизе.

## Подготовка новой версии плагина

Нужны Windows, .NET SDK 10 и совместимые библиотеки Dalamud API 15.
Для публикации нужны Git и авторизованный GitHub CLI `gh`.

1. Согласовать `Version`, `AssemblyVersion`, `FileVersion` в проекте и
   `PluginVersion` в `Plugin.cs`. Для изменения игрового кода использовать новую версию.
2. Обновить главную страницу, инструкцию, `CHANGELOG.md`, `CURRENT_STATE.md`
   и `VERIFICATION.md`. Отдельно записать автоматические и игровые проверки.
3. Подготовить `docs/releases/ВЕРСИЯ.md`: что изменилось, какие файлы скачать,
   как установить, какие ограничения остались.
4. Выполнить из корня исходников:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/Build-Local.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/Test-Local.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/Package-Local.ps1
```

Сборка Release не устанавливает плагин в игру. Упаковка сверяет каждый файл
ZIP и его SHA-256, проверяет версию DLL и запрещает исходники, отладочные файлы,
скрипты и EXE внутри ручного архива. Если имя уже занято, добавляется время;
нужный путь указан в результате `Package-Local.ps1`.

5. Проверить изменения и по разрешению владельца сохранить и отправить исходники.
   Логи, настройки, резервные копии и сборки из `artifacts` в Git не добавляются.
6. Передать путь нового ZIP и описание выпуска в `scripts/Publish-Release.ps1`
   сначала с `-CheckOnly`, затем без него для публикации.

`-CheckOnly` сверяет архив, сборку и отправленный коммит без создания выпуска.
Скрипт отказывает при несохранённых изменениях, чужом адресе репозитория,
несовпадении файлов или уже существующей метке. Он не заменяет запуск тестов
и не проверяет поведение игры.

## Автоустановщик

Исходники EXE с тестами и инструкцией сборки находятся в отдельном архиве
`FF14AccessibilityInstaller-1.1.2-source.zip`. Распакуйте его в отдельную папку
и следуйте включённому `Installer/Russian/README.md`.
EXE и его исходники распространяются отдельными файлами релиза, вне ZIP мода.

29 сентября 2026 по просьбе владельца в выпуске v6.08.73 оставлены текущий
EXE 1.1.2 и исходники только этой версии. Архивы исходников 1.0.0, 1.1.0
и 1.1.1 убраны из загрузок после сохранения проверенных локальных копий.
Архив игрового плагина и `SHA256SUMS.txt` нужны автоустановщику и сохранены.

В опубликованном комплекте исходников плагина сборка русского установщика
предоставлена этим отдельным архивом. В локальном рабочем комплекте также
есть дополнения к сборке и публикации, которые могут прикладывать EXE автоматически.
Перед выпуском проверьте фактический набор Assets: готовый мод, EXE, исходники
установщика и соответствующие контрольные суммы.

После публикации скачайте файлы обратно, сравните SHA-256 и проверьте,
что EXE находит новый пакет. Запишите результат в `VERIFICATION.md`.
При обрыве публикации сначала осмотрите состояние на GitHub; не передвигайте
метку и не удаляйте выпуск ради повторного запуска.

## Переупаковка 6.08.73 — 29 сентября 2026

По отдельному запросу владельца текущий ZIP переупакован для ручной установки.
Удалены два установочных скрипта, заменена инструкция. Все 138 файлов внутри
`plugin` побайтово совпадают с прежним опубликованным архивом. Изменена
контрольная сумма ZIP; метка, версия и DLL плагина сохранены.
Прежний архив и его контрольные суммы сохранены локально.

Новый пакет содержит 141 файл. Он скачан обратно с GitHub и проверен;
автоустановщик успешно использовал его в отдельной проверочной папке.
EXE, его исходники и `installer-SHA256SUMS.txt` не заменялись.

основу автора. Игроков направляют на README, инструкцию и последний релиз.
