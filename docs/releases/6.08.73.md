## Установка через EXE

Нужны Windows x64, FFXIV, XIVLauncher с Dalamud API 15 и скринридер.
При первой настройке XIVLauncher один раз войдите в игру с включённым Dalamud.

1. Закройте игру и XIVLauncher, скачайте и запустите EXE.
2. Дождитесь проверки и нажмите **«Установить / обновить мод»**.
3. При необходимости согласитесь на предложенную установку vnavmesh для маршрутов.
4. После завершения запустите игру через XIVLauncher. Русский язык: `/acc lang ru`.

Для следующего обновления снова запустите EXE. Он сам включает мод в Dalamud,
проверяет скачанные файлы и сохраняет прежние файлы и настройки перед заменой.
Более новая установленная версия не заменяется старой.

## Ручная установка

Распакуйте ZIP, закройте игру и лаунчер, сохраните копию прежней папки мода.
Скопируйте всё содержимое `plugin` в
`%APPDATA%\XIVLauncher\devPlugins\FF14Accessibility`.
При первой установке добавьте полный путь к `FF14Accessibility.dll` в
Dalamud Settings → Experimental → Dev Plugin Locations, затем включите плагин
и его загрузку при запуске. vnavmesh для этого способа устанавливается отдельно.

[Полная инструкция](https://github.com/pitpamyati-netizen/ff14-accessibility/blob/feature/russian-accessibility-recovery/docs/installation.md)
также включена в архив как `README-RU.txt`.

## Что нового в моде

- `FFXIV_Keybinds.txt` больше не создаётся на рабочем столе при входе в игру.
  Список клавиш сохраняется по команде `/acc keys`.
- Подходящие классы и места экипировки читаются по-русски.
- При застревании у края подъёма добавлен поиск короткого подхода сбоку.
  Повторное Num3 отменяет движение; автоматических прыжков нет.
- Расширены русские названия и описания предметов, умений и эффектов,
  переведены 3 813 фраз внешности, используемых плагином. Перевод встроен.

## Проверки и ограничения

Сборка и автоматические проверки выполнены; результаты находятся в
[журнале проверок](https://github.com/pitpamyati-netizen/ff14-accessibility/blob/feature/russian-accessibility-recovery/docs/maintenance/VERIFICATION.md).

проверки в FFXIV. Остаётся замечание о лишнем чтении умений окружающих игроков.
Доступность элементов окна установщика проверена; речь NVDA и реальный
проход по кнопкам клавишей Tab ещё не подтверждены.
