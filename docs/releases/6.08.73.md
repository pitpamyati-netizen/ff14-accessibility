# FF14 Accessibility 6.08.73 — русская версия

Первый GitHub-релиз этой русской ветки. Включает накопленные изменения перевода,
чтения экипировки, навигации и клавиатурного управления.

## Что нового

- Файл `FFXIV_Keybinds.txt` больше не появляется автоматически при входе в игру.
  Сохранить список клавиш можно командой `/acc keys`; предупреждения о конфликтах сохранены.
- Подходящие классы и профессии, а также места экипировки читаются по-русски.
  У колец обе руки названы как варианты; учитываются вещи, занимающие несколько мест.
- При застревании у края подъёма автобег ищет короткий обход сбоку.
  Повторное Num3 отменяет движение. Автоматических прыжков нет.
- Включены русские названия доступных предметов, умений, маунтов, спутников,
  эмоций и эффектов из проверенных таблиц игры, а также все 3 813 описываемые
  плагином фразы внешности. Перевод встроен в плагин и работает без сети.

## Установка

1. Скачайте **FF14Accessibility-6.08.73-RU-no-source.zip** из раздела Assets.
2. Распакуйте архив целиком и закройте игру и XIVLauncher.
3. Запустите `install.bat`, прочитайте результат, затем запустите игру.
4. Для русского языка плагина используйте `/acc lang ru`.

Нужны Windows, XIVLauncher с совместимым Dalamud API 15 и скринридер.
Для маршрутов нужна совместимая vnavmesh, устанавливаемая отдельно.
При первой установке может потребоваться зарегистрировать DLL как плагин разработчика
в Dalamud; установщик сам эту настройку не меняет. Подробности находятся в README-RU.txt
в архиве. Обновления исходного мода могут заменить русскую сборку — используйте релизы этого форка.

## Проверки и ограничения

- Release собран без ошибок; остаются 9 ранее известных предупреждений.
- Все 86 автоматических тестов пройдены без пропусков.
- Проверены состав и контрольные суммы всех 143 файлов ZIP, включая основную DLL.
- Архив содержит готовый плагин, установщик и лицензии, **без исходного кода**.
  Исходники этой версии доступны отдельно через Source code на этой странице.
- Новая речь, обход подъёмов, вход в игру и ручная команда сохранения клавиш
  требуют дальнейшей проверки в FFXIV. Автоматические тесты не заменяют такую проверку.
- Остаётся открытым замечание о лишнем чтении умений окружающих игроков.
- Перевод проверен по данным игры `2026.09.15.0000.0000`. Служебные записи без
  доступного текста не переведены; изменившиеся после патча строки читаются из игры.

`SHA256SUMS.txt` содержит контрольные суммы установочного архива и основной DLL.
Файлы Source code не являются установщиком.
