# FF14 Accessibility — русская версия

Доступность **FINAL FANTASY XIV для незрячих игроков**: озвучивание окон, диалогов,
предметов и умений, управление с клавиатуры и звуковая навигация.
Плагин работает через Dalamud и передаёт речь скринридеру, в том числе NVDA.

## Что умеет плагин

- Читает поддерживаемые меню, диалоги, задания, инвентарь, магазины и награды.
- Произносит русские названия и описания предметов, умений и эффектов.
- Описывает доступные варианты внешности при создании персонажа.
- Помогает выбирать цели, узнавать расстояние и направление, двигаться по маршруту.
- Позволяет назначать боевые и ремесленные действия с клавиатуры.
- Читает материалы выбранного рецепта, подходящие классы и места экипировки.
- Поддерживает звуковые подсказки и отдельные способы управления с геймпада.

Русский язык плагина выбирается командой `/acc lang ru`. Перевод встроен в плагин
и работает без сети. Он относится к озвучиванию и сообщениям плагина;
полный визуальный перевод самой игры устанавливается отдельно.

## Скачать и установить

Текущий выпуск: **6.08.73**. Нужны Windows, FINAL FANTASY XIV,
XIVLauncher с совместимым Dalamud API 15 и настроенный скринридер.
Для расчёта маршрутов нужна совместимая vnavmesh; она не входит в архив.

1. Откройте [последний релиз](https://github.com/pitpamyati-netizen/ff14-accessibility/releases/latest).
2. В разделе **Assets** скачайте `FF14Accessibility-6.08.73-RU-no-source.zip`.
   Файлы **Source code** предназначены для разработчиков и не содержат готового плагина.
3. Распакуйте архив целиком в отдельную папку.
4. Закройте игру и XIVLauncher, затем запустите `install.bat`.
5. Прочитайте результат установки и запустите игру.

При первой установке может потребоваться включить режим разработчика Dalamud,
добавить `%APPDATA%\XIVLauncher\devPlugins\FF14Accessibility\FF14Accessibility.dll`
в список плагинов разработчика и включить его. Установщик сообщает об отсутствии
этой настройки, но не меняет её автоматически. Подробности — в [инструкции](README-RU.txt).

При обновлении установщик сохраняет прежний основной файл плагина как
`FF14Accessibility.dll.bak`. Обновления русской версии скачивайте из релизов
этого проекта: установщик исходного мода может заменить её версией автора.

## Последние изменения

- **6.08.73:** файл `FFXIV_Keybinds.txt` больше не создаётся автоматически
  при входе в игру. Команда `/acc keys` сохраняет его по запросу.
- **6.08.72:** добавлен поиск короткого обхода сбоку, если автобег застрял
  у края подъёма. Прыжки автоматически не выполняются.
- **6.08.71:** русские списки подходящих классов и подсказки о том,
  куда надевается предмет, включая кольца и вещи, занимающие несколько мест.
- **6.08.70:** дополнены русские названия предметов, умений и эффектов,
  переведены все 3 813 разных фраз внешности, описываемой плагином.

Полная история текущего выпуска — в [CHANGELOG.md](CHANGELOG.md).

## Что проверено и что ещё требует проверки

Для 6.08.73 выполнены сборка, 86 автоматических тестов и проверка всех файлов
установочного ZIP. Архив содержит готовый плагин, установщик и лицензии, **без исходников**.
Исходники соответствующего выпуска доступны по его метке на GitHub.

Последние изменения речи, обход подъёмов и поведение файла клавиш при настоящем
входе в FFXIV ещё требуют проверки в игре. Сборка и тесты не доказывают их работу
в игровом окне. Сохраняется открытое замечание о лишнем чтении умений окружающих
игроков. После обновлений игры для изменившихся строк может использоваться исходный
игровой текст. Подробные результаты — в [журнале проверок](docs/maintenance/VERIFICATION.md).
