# Проверка входов между зонами

Инструмент читает таблицы установленной игры и запускает настоящий поиск
переходов PlacesService без обращения к процессу FFXIV. Входы требуют явной
связи EObj → Warp → PopRange и исходной строки Level. Положение появления
внутри помещения никогда не используется как положение внешнего входа.

Для входа в Обитель Первого Лука проверяются Warp131074, охранник1000423,
DefaultTalk590353, Level3861082 и его присутствие в задании Quest65983.
Другие входы через NPC без проверенной связи не угадываются.

```powershell
dotnet run --project tools/cross-zone-check/CrossZoneCheck.csproj -c Release -- "D:\games\Steam\steamapps\common\FINAL FANTASY XIV Online\game\sqpack" "artifacts/cross-zone-check.json"
```

Проверяются маршрут из Новой/Старой Гридании к входу, обратный выход через
настоящую дверь, прежний обычный выход в Центральную чащу, неизвестные карты
и все найденные прямые входы. Это проверка данных и выбора пути; живое
движение, доступность входа по прогрессу задания, подтверждение Num0,
переход зоны и речь NVDA/Tolk требуют отдельной проверки в игре.
