# Проверка входов между зонами

В 6.08.111 дополнительно проверяется Quest65646 «Дилемма изящного вкуса»:
реальная Level5058426/Type51/Object0 и общий выбор поверхности с ответом
сетки из журнала, на 15,6 м выше центра поискового круга. Радиус 35 м взят
из нативной отметки в журнале, а не из Level.Radius (там 303).
Обход 5 689 расположений Level51 использует одинаковый имитированный
радиус 35 м и поверхность; текущие нативные радиусы и живые пути других
заданий он не измеряет. Срез 6.08.111: 14 071 утверждение, пять записанных
заданий, SharedAreaResolverChecked=true, NativeFfxivChecked=false.

В 6.08.110 проверяются также полные прямоугольные объёмы пеших переходов
во всех территориях игровых таблиц: 125 объёмов, включая 68 высоких.
Настоящий ExitRange Middle → Lower La Noscea проверяется с краем сетки
из журнала 7 октября. Вызывается общий выбор цели плагина, используемый
обоими режимами движения; широкий повторный поиск не должен вернуть
точку на высоте 91,5 вместо дороги 71,75. Ответ сетки здесь воспроизведён
по журналу, а не получен из работающего vnavmesh. Отчёт явно хранит это
различие. Срез 6.08.110: 2 687 утверждений; NativeFfxivChecked=false.

В 6.08.109 дополнительно читаются MapRange, точные PopRange и пешие ExitRange.
Карта прибытия исправляется по фактическому объёму карты; разные этажи одной
территории остаются разными узлами, повторные строки одной физической карты
объединяются по полному ключу. NPC/прибытия без Level проверяются по файлам зоны.
CustomTalk допускается только при явной Warp-ссылке.

Инструмент читает таблицы и расположение объектов всех карт установленной игры
и запускает настоящий поиск PlacesService без обращения к процессу FFXIV.
Входы связывают NPC/EObj с Warp напрямую, через PreHandler/ArrayEventHandler
или однозначное событие отказа DefaultTalk. Объекты, которых нет в Level,
получают исходное положение из файлов зоны. Карта без явной привязки допустима
только в зоне с одной различимой картой; этажи не угадываются.

Обитель Первого Лука и сценарный вход Лотоса дополнительно проверяют связи
с заданиями65983/65985. SwitchTalk не хранит назначение в клиентской таблице;
неизвестные сценарные входы не угадываются. Положение появления в чужой зоне
никогда не используется как положение внешнего входа.

```powershell
dotnet run --project tools/cross-zone-check/CrossZoneCheck.csproj -c Release -- "D:\games\Steam\steamapps\common\FINAL FANTASY XIV Online\game\sqpack" "artifacts/cross-zone-check.json"
```

Проверяются оба задания, маршрут из гостиницы через город к Лотосу,
правильная дверь первого участка, обратные выходы, прежний пеший выход в
Центральную чащу, неизвестные карты, каждый найденный прямой вход и
согласованность поиска со списком расстояний. Отчёт содержит полный набор
найденных входов и количество просмотренных карт.

Это проверка данных и выбора пути. Активность игровых слоёв, движение,
доступность и возможная плата за транспорт, Num0, переход зоны и NVDA/Tolk
требуют отдельной проверки в игре. Подтверждения выполняются самой игрой.

Проверяются также свежие Quest66043/65640: воздушное сообщение из Гридании,
подъёмник посадочной площадки Лимсы, вход и выход гильдии разбойников.
Каждая строка Map проверяется на правильную каноническую идентичность.
Обход Quest берёт все указанные в сценарных константах расположения NPC/EObj,
считает доступные карты назначения и отдельно сохраняет непокрытые.
Подсказки телепортации/подземелий здесь означают только возможную связь:
доступность у персонажа проверяется нативно во время игры.

Срез 6.08.109: 2 305 утверждений, 315 входов на 147 исходных картах,
1 231 просмотренная карта, 26 726 расположений на 247 картах назначения.
106 строк карты назначения не имеют подтверждённого пути из Map2 с учётом
дополнительных средств. Поле NativeFfxivChecked=false обязательно сохраняется.
Это не число сломанных квестов и не доказательство прохождения каждого этапа.
