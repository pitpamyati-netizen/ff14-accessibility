# Проверка обхода подъёма

Повторяет застревание из журнала от 27 сентября 2026, 17:26–17:29,
Центральный Таналaн (территория 141), возле Хихияджи. Исходная точка:
`(58.22726, 1.0359972, 262.0598)`, следующий угол: `(58.25, 1.75, 261.5)`.

Использует установленную библиотеку vnavmesh и настоящий `GroundDetour.cs`
плагина. Выводит исходный путь, проверку запрета проблемного участка,
соседние подходы и результат расчёта нового обработчика.
Кэш не изменяется. Игра, управление персонажем и речь не запускаются.

```powershell
dotnet run --project tools/ground-detour-check/GroundDetourCheck.csproj -c Release
```

Нужны vnavmesh в `devPlugins/vnavmesh`, Dalamud в `addon/Hooks/dev` и
сохранённые карты Центрального Таналана в `pluginConfigs/vnavmesh/meshcache`.
Отсутствие нужного кэша завершается ошибкой, а не пропуском.
Проверка двух вариантов карты подтверждает расчёт, но не физическое прохождение уступа.
